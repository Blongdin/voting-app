# 운영자 인증은 환경변수 비밀번호 하나로 한다

운영자 계정 테이블을 두지 않는다. 비밀번호 하나를 환경변수 `ADMIN_PASSWORD`에 두고 상수 시간 비교로 확인한 뒤, `SESSION_SECRET`으로 서명한 HttpOnly 세션 쿠키를 1일간 발급한다. 운영자를 개별 계정으로 구분할 필요가 없고, 이렇게 하면 DB 스키마와 비밀번호 해시 관리가 필요 없어진다.

## Consequences

- 누가 어떤 작업을 했는지 기록할 수 없다.
- 로그인 시도 제한이 없다. 서버리스 환경에서 제대로 하려면 별도 저장소가 필요하기 때문이다. 대신 비밀번호를 길고 무작위하게 정하는 것을 전제로 한다.
- 권한은 `proxy`가 아니라 각 Server Action과 운영자 페이지 안에서 `requireAdmin()`으로 확인한다. Server Action은 경로와 상관없이 직접 호출될 수 있기 때문이다.
