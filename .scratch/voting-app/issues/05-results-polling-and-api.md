# 05: 결과 5초 폴링과 결과 API

**What to build:** 진행 중인 투표의 결과 화면이 새로고침 없이 5초마다 갱신된다. 참여자 화면과 운영자 화면 모두 해당한다. 이를 위해 결과 조회 API를 만들며, 이 API도 결과 공개 규칙을 그대로 따른다. 그래서 주소를 직접 호출해도 표를 내기 전에는 결과를 받을 수 없다.

**Blocked by:** 04 (참여자의 표 내기와 결과 보기)

**Status:** ready-for-agent

- [ ] 결과 조회 Route Handler 하나가 투표 ID를 받아 도메인 모듈의 결과 조회를 그대로 따른다.
  - 권한 없음: 403
  - 없는 투표: 404
  - 성공: 200과 결과 본문. 본문 형태는 스펙의 결과 API 계약을 따른다.
- [ ] 응답은 캐시하지 않는다.
- [ ] 표를 내지 않은 브라우저에서 진행 중인 투표의 결과 API를 직접 호출하면 403이다. 직접 실행해서 확인한다.
- [ ] 진행 중인 투표의 결과 화면이 5초마다 결과 API를 다시 호출하고 화면을 갱신한다. 다른 브라우저에서 표를 내면 5초 안에 반영된다.
- [ ] 탭이 숨겨지면 폴링이 멈추고, 다시 보이면 이어서 한다.
- [ ] 응답에서 투표가 마감됐다고 나오면 폴링이 멈추고 "마감됨" 상태가 표시된다.
- [ ] 운영자 화면의 결과 보기에서도 같은 방식으로 폴링된다.
