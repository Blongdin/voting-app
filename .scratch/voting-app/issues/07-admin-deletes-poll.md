# 07: 운영자의 투표 삭제

**What to build:** 운영자가 "이 투표와 표 N개가 삭제됩니다" 확인 창을 거쳐 투표를 삭제한다. 투표의 선택지와 표까지 함께 완전히 지워지고, 복구 기능은 없다. 삭제한 투표는 목록에서 사라지고, 그 링크는 404 페이지를 보여 준다.

**Blocked by:** 03 (운영자가 투표를 만들고, 참여자가 목록과 투표 화면에서 확인)

**Status:** ready-for-agent

- [ ] 도메인 모듈에 **투표 삭제(행위자, 투표 ID)**가 있다.
  - 운영자가 아닌 행위자의 요청은 거절된다.
  - 선택지와 표는 DB의 연쇄 삭제로 함께 지워진다.
- [ ] 테스트가 통과한다.
  - 삭제한 투표는 목록과 조회에서 사라진다. 조회 결과는 "없음"이다.
  - 04가 완료된 뒤라면, 삭제한 투표의 결과 조회도 "없는 투표"다.
  - 운영자가 아닌 행위자의 삭제는 거절된다.
- [ ] 운영자 화면에서 삭제 버튼을 누르면 해당 투표의 총 표 수가 들어간 "이 투표와 표 N개가 삭제됩니다" 확인 창이 뜬다.
- [ ] 삭제한 투표는 홈 목록과 운영자 목록에서 사라진다.
- [ ] 삭제한 투표의 링크로 들어가면 404 페이지가 보인다.
