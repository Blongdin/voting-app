# 04: 참여자의 표 내기와 결과 보기

**What to build:** 참여자가 로그인 없이 투표 화면에서 선택지 하나를 골라 표를 내면 결과 화면으로 넘어간다. 한 브라우저는 투표마다 한 표만 낼 수 있고, 낸 표는 바꿀 수 없다. 결과는 표를 낸 참여자와 운영자만 볼 수 있다. 운영자는 표를 내지 않아도 볼 수 있다. 결과가 자동으로 갱신되지는 않고 새로고침할 때만 바뀐다(자동 갱신은 05).

**Blocked by:** 03 (운영자가 투표를 만들고, 참여자가 목록과 투표 화면에서 확인)

**Status:** done

- [x] 첫 표를 낼 때 무작위 UUID 참여자 ID가 HttpOnly, Secure, SameSite=Lax 쿠키로 1년 유효기간으로 발급된다(ADR-0001).
- [x] 도메인 모듈에 **표 내기(투표 ID, 선택지 ID, 참여자 ID)**가 있다.
  - 결과는 성공, 이미 표를 냄, 마감됨, 잘못된 선택지, 없는 투표 중 하나다.
  - 중복 표와 다른 투표의 선택지는 DB 제약으로 막는다. 마감 여부는 표를 넣는 같은 SQL 문 안에서 확인한다(ADR-0004).
- [x] 도메인 모듈에 **결과 조회(투표 ID, 보는 사람)**가 있다.
  - 보는 사람이 표를 냈거나, 투표가 마감됐거나, 보는 사람이 운영자일 때만 결과를 돌려준다. 그 밖에는 "권한 없음"이다.
  - 결과에는 선택지별 {ID, 문구, 표 수, 정수 비율}(표시 순서대로), 총 표 수, 보는 사람이 고른 선택지 ID가 들어간다.
- [x] 테스트가 통과한다.
  - 표 내기에 성공하면 결과에 반영된다.
  - 같은 참여자의 두 번째 표는 "이미 표를 냄"이 되고 표 수가 변하지 않는다.
  - 같은 참여자의 표 두 개를 동시에 보내도 하나만 들어간다.
  - 다른 투표의 선택지로 낸 표는 "잘못된 선택지"다.
  - 없는 투표에 낸 표는 "없는 투표"다.
  - 표를 내지 않은 참여자와 참여자 ID가 없는 사람은 진행 중인 투표의 결과를 받지 못하고, 운영자는 받는다.
  - 비율이 맞다. 0표일 때는 모두 0이다.
- [x] 투표 화면에서 선택지를 고르지 않으면 표를 낼 수 없고, 표를 내기 전에 "낸 표는 바꿀 수 없습니다"라는 안내가 보인다.
- [x] 표를 내면 결과 화면으로 넘어간다. 결과에는 선택지별 표 수, 비율(%), 막대, 총 표 수, 내가 고른 선택지 표시가 나온다.
- [x] 이미 표를 낸 투표에 다시 들어가면 투표 양식 대신 결과가 보인다.
- [x] 이미 표를 냈는데 다시 표를 내려 하면(예: 다른 탭에서) "이미 참여한 투표입니다" 안내와 함께 결과가 보인다.
- [x] "잘못된 선택지"는 일반 오류 안내로 보인다.
- [x] 운영자는 운영자 화면에서 투표마다 결과를 볼 수 있다.
- [x] 홈 목록과 운영자 목록의 총 표 수가 실제 표 수와 같다.

  - 마감 뒤에는 누구나 결과를 보고, 새로 낸 표는 "마감된 투표입니다."로 거절된다.

  - 표가 거절돼도 쿠키가 발급됐다.
  - 투표가 도중에 삭제되면 "잘못된 선택지"로 잘못 분류됐다.
  - 마감과 동시에 들어온 표가 마감 뒤로 섞일 수 있었다. `FOR SHARE`로 막았다.
