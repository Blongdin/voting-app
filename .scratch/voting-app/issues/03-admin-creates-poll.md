# 03: 운영자가 투표를 만들고, 참여자가 목록과 투표 화면에서 확인

**What to build:** 운영자가 운영자 화면에서 질문과 선택지(2~10개)를 입력해 투표를 만든다. 만든 투표는 홈 목록에 진행 중으로 나타나고, 투표마다 고유 링크로 질문과 선택지를 볼 수 있다. 표 내기는 아직 없어서 선택지는 보기만 한다. 없는 투표의 링크는 404 페이지를 보여 준다.

**Blocked by:** 01 (기반 구축), 02 (운영자 로그인과 로그아웃)

**Status:** ready-for-agent

- [ ] 도메인 모듈에 **투표 만들기(행위자, 질문, 선택지 목록)**와 **투표 하나 조회**가 있다. 투표와 선택지는 한 트랜잭션 안에서 함께 만든다.
- [ ] 입력은 앞뒤 공백을 지운 뒤 검증한다.
  - 질문: 1~200자
  - 선택지: 2~10개, 각 1~100자
  - 한 투표 안의 선택지 중복 불가: 공백 제거 후 대소문자를 구분해 비교
  - 실패하면 어느 항목이 왜 틀렸는지 담긴 결과를 돌려주고, 운영자 화면에 한국어로 보인다.
- [ ] 운영자가 아닌 행위자의 만들기 요청은 거절된다. Server Action을 직접 호출해도 거절된다.
- [ ] 테스트가 통과한다.
  - 올바른 입력은 성공한다.
  - 빈 질문, 200자 초과 질문, 선택지 1개, 선택지 11개, 빈 선택지, 100자 초과 선택지, 중복 선택지(공백 제거 후 비교 포함)는 각각 거절된다.
  - 운영자가 아닌 행위자의 만들기는 거절된다.
  - 없는 투표를 조회하면 "없음"이다.
- [ ] 운영자 화면에서 선택지 입력 칸을 2~10개 사이로 늘리고 줄일 수 있다.
- [ ] 투표를 만든 직후 그 투표의 링크가 보인다.
- [ ] 운영자 화면에 모든 투표가 상태, 총 표 수와 함께 나온다.
- [ ] 홈 목록에 새 투표가 나오고, 투표 화면에 질문과 선택지가 표시 순서대로 보인다.
- [ ] 없는 투표 ID로 들어가면 "찾을 수 없는 투표" 404 페이지가 보인다.
