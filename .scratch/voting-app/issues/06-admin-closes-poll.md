# 06: 운영자의 투표 마감

**What to build:** 운영자가 진행 중인 투표를 확인 창을 거쳐 마감한다. 마감된 투표는 더는 표를 받지 않고, 투표 양식 대신 "마감됨" 표시와 결과를 누구나(표를 내지 않았어도) 볼 수 있다. 홈 목록에서는 진행 중인 투표들 아래로 내려간다. 마감은 되돌릴 수 없다.

**Blocked by:** 04 (참여자의 표 내기와 결과 보기)

**Status:** done

- [x] 도메인 모듈에 **투표 마감(행위자, 투표 ID)**이 있다.
  - 운영자가 아닌 행위자의 요청은 거절된다.
  - 이미 마감된 투표를 다시 마감하면 아무것도 바뀌지 않는다.
  - 마감을 되돌리는 기능은 없다.
- [x] 테스트가 통과한다.
  - 마감된 투표에 낸 표는 "마감됨"이다.
  - 운영자가 아닌 행위자의 마감은 거절된다.
  - 누구나(참여자 ID가 없는 사람 포함) 마감된 투표의 결과를 받는다.
  - 마감된 투표가 목록에서 진행 중인 투표 뒤에 온다.
- [x] 운영자 화면에서 마감 버튼을 누르면 "마감은 되돌릴 수 없습니다" 확인 창이 뜬다.
- [x] 마감된 투표 화면에는 투표 양식이 없고 "마감됨" 표시와 결과가 보인다.
- [x] 투표 양식을 보는 사이에 마감되어 표가 거절되면 "마감된 투표입니다" 안내와 함께 결과가 보인다.
- [x] 홈 목록과 운영자 목록에서 마감된 투표의 상태가 "마감"으로 보이고, 진행 중인 투표들 아래에 온다.
