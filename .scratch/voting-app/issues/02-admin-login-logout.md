# 02: 운영자 로그인과 로그아웃

**What to build:** 운영자가 비밀번호로 운영자 화면에 로그인하고, 로그아웃 버튼으로 나갈 수 있다. 로그인은 1일간 유지된다. 로그인하지 않은 사람은 운영자 화면 대신 로그인 화면을 본다. 이 티켓으로 운영자 인증 모듈과, 이후 모든 운영자 기능이 쓸 공통 운영자 확인 헬퍼가 생긴다(ADR-0002).

**Blocked by:** 01 (기반 구축: 빈 투표 목록을 Vercel에 배포)

**Status:** ready-for-agent

- [ ] 운영자 인증 모듈이 DB 없는 순수 모듈이다. 인터페이스는 **로그인(비밀번호)**과 **세션 검증(토큰, 현재 시각)** 두 가지다.
- [ ] 비밀번호는 상수 시간으로 비교하고, 세션 토큰은 세션 서명 키로 서명한다.
- [ ] 인증 모듈 테스트가 통과한다.
  - 맞는 비밀번호는 세션을 발급하고, 틀린 비밀번호는 실패한다.
  - 발급 직후 세션은 유효하다.
  - 1일이 지난 세션, 변조된 토큰, 다른 서명 키로 만든 토큰은 무효다.
- [ ] 로그인하면 HttpOnly, Secure, SameSite=Lax 세션 쿠키가 1일 유효기간으로 발급된다.
- [ ] 틀린 비밀번호에는 "비밀번호가 올바르지 않습니다" 안내가 보인다.
- [ ] 로그인하지 않은 상태로 운영자 화면에 들어가면 로그인 화면이 나온다. 이 확인은 `proxy`에만 맡기지 않고 운영자 페이지 안에서도 한다.
- [ ] 운영자 화면에 로그아웃 버튼이 있다. 누르면 세션 쿠키가 지워지고 로그인 화면으로 이동한다.
- [ ] 이후 Server Action들이 쓸 공통 운영자 확인 헬퍼가 있다. 쿠키를 읽어 "운영자인지"를 판단한다.
